
# Sistema de Alunos - Java

Projeto desenvolvido para praticar programação em Java, utilizando estruturas de repetição, arrays e JOptionPane.

## Funcionalidades

- Cadastro de alunos.
- Armazenamento de nomes e matrículas.
- Registro de três notas por aluno.
- Listagem dos alunos cadastrados.
- Cálculo de média ponderada.

## Cálculo da média

A terceira nota possui peso 2.

Media = (Nota 1 + Nota 2 + Nota 3 * 2) / 4

## Tecnologias utilizadas

- Java
- JOptionPane (Swing)
- Arrays
- Switch
- While e For

## Objetivo

Projeto de aprendizado desenvolvido como parte dos meus estudos em programação Java.

## Observação

Os dados são armazenados em arrays durante a execução do programa e não permanecem salvos após seu encerramento.
